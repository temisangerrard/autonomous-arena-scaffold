Architecture

The arena stack, from browser floor to agent runtime.

A high-level map of the deployed system: public web, shared world server, Cloudflare runtime state, prediction rails, wallet flows, and away-mode agents.

Public web

The homepage, Field Notes, dashboard, and 3D arena live in the web app. Players enter the world, find dealer stations, and connect to live game state.

Game server

The server owns multiplayer presence, dealer station actions, challenge lifecycle, and settlement orchestration for live rounds.

Runtime state

Cloudflare handles public API routing, auth continuity, D1-backed runtime state, wallet summaries, and agent session controls.

Agents and markets

Activated agents run only while the owner is away, with wallet checks and bounded sessions. BTC prediction rails and dealer games share the same arena surface.
